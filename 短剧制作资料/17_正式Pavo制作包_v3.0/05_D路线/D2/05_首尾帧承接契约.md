# D2｜首尾帧承接契约

## 输入来源

## 输入必须继承

- 竞争者已经提出报价
- 交易对象是完整勘探资料
- 报价可以回收大部分前期投入
- 交付后永久放弃未来控制机会

## 本段允许变化

- 从营地过渡到基地资料核验
- 核验四类勘探资料
- 接受资本回收并进入自动交付结果

## 目标尾帧

资料核验完成后的交付决策状态：文件四类齐全，样本箱不在交付区，收购方准备接收，队伍明确主动退出。

## 下一段去向
