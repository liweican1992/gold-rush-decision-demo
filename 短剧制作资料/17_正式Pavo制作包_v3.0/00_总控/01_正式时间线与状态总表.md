# 《最后十四天》正式时间线与状态总表 v3.0

## 时间口径

- 土地购买期权登记窗口从公共开场起只剩 14 天。
- “第 N 天”指从发现黄金当天开始计数；“剩余 N 天”指该节点行动完成后至截止时刻的可用时间。
- 超期节点只允许撤离、资产保存、复盘或退出，不再出现赶路、登记、提交等可挽回当前机会的选项。
- 资料、样本、设备、人员状态不会在分支切换后自动恢复。

## A2 专项时间闭合

```text
第3天 A0 做出“背风处扎营等待一天”
  → 第4天清晨 A2，剩余10天
  → A2-1 全队轻装约9天：第13天提交，剩余1天
  → A2-2 资料组轻装约8天：第12天提交，剩余2天
  → A2-3 重装安全节奏无可靠余量：抵达时窗口已关闭
```

不得再使用旧版“A2 第10天、剩余4天”的口径，也不得把扎营一夜表现成已经越过山口。

## 报告分类口径

| 分类 | 正式定义 | 画像倾向 |
| --- | --- | --- |
| F1 | 按时提交，人员、证据与执行能力基本可持续 | 平衡执行型 |
| F2 | 按时提交，但承受明确人员、证据、设备或组织损失 | 高承诺推进型 |
| F3 | 借助当地运输队提交，并让渡部分未来权益或决策空间 | 生态合作型 |
| F4 | 出售完整勘探资料，回收资本并退出 | 选择权管理型 |
| F5 | 无论窗口是否仍开放，都优先人员与可迁移能力并安全撤离 | 稳健韧性型 |
| F6 | 窗口关闭后保存知识、设备或组织能力并复盘重构 | 复盘重构型 |
