# 《最后十四天》v3.0 制作文件规范

## 适用范围

本规范适用于 `01_公共开场/`、`02_A路线/`、`03_B路线/`、`04_C路线/`、`05_D路线/` 中的 52 个制作单元：INTRO、PRIMARY、A0—D3 共 16 个正式节点和 34 条独立终局。

正式剧情事实以 `src/demo/redesignedStory.ts`、`01_正式时间线与状态总表.md` 和 `02_34条路径总表.md` 为准。制作文件只能展开镜头、声音和承接方式，不得改变时间、地点、人物、装备、伤势、样本/资料、天气及不可逆后果。

## 每个制作单元的固定内容

每个制作单元必须包含以下六份文档和四个空白交付目录：

| 文件或目录 | 唯一职责 | 不得承担 |
| --- | --- | --- |
| `00_节点状态卡.md` | 进入状态、离开状态、玩家已知事实、不可逆事实 | 镜头风格和生成参数 |
| `01_逐镜文字脚本.md` | S01/S02 的时长、景别、动作和结束画面 | 改写正式结果 |
| `02_对白与声音.md` | 角色对白、环境声、对白落点 | 烧录字幕或画面文字 |
| `03_Pavo正式提示词.md` | 每段可复制投喂的正向提示词和硬性负向约束 | 宣称关键帧已验收 |
| `04_关键帧生成提示词.md` | K01 输入首帧、K02 动作参考、K03 目标尾帧 | 用计划镜头冒充真实尾帧 |
| `05_首尾帧承接契约.md` | 上一段输入来源、本段目标尾帧、下一段承接状态 | 跨分支共用已发生事实 |
| `关键帧/` | 经人工验收的 K01/K02/K03 | 未验收旧图 |
| `Pavo原片/` | Pavo 无字幕源片 | 带水印预览或旧共享结局 |
| `字幕/` | 根据最终音轨校时的字幕 | Pavo 自动转写结果 |
| `验收/` | 图像、视频、对白和连续性记录 | 仅用文件存在证明通过 |

## 节点状态卡规则

状态卡固定包含：

1. 节点 ID、类型、正式时间和所属路线。
2. 进入状态：本段开始前已确定的地点、人物、物资、伤势和外部角色。
3. 离开状态：本段结束后必须真实发生、可供下一次选择使用的事实。
4. 玩家已知事实：作出下一选择前已经看见或听见的内容。
5. 不可逆事实：遗失、受潮、让渡、超期、退出、伤势加重等不得在后续自动恢复的内容。
6. 禁止误写：该节点最容易与旧剧情混淆的具体禁区。
7. 制作状态：初始统一为“制作脚本已写，关键帧未验收，视频未生成”。

## 逐镜脚本规则

- 每段源片编号为 S01、S02；单段时长 8—12 秒。
- 单段只表现一个连续空间内的主要动作，最多两句短对白。
- 跨地点、跨日或同时包含“行动、到达、提交”的结果必须拆段。
- 每段按秒区间写景别、镜头运动、主体动作、可见事实和结束构图。
- 第一人称镜头中不生成玩家正脸；队长身份通过视线、受伤左手、呼吸和队友回应建立。
- 时间信息通过环境、动作和最终字幕层表达；Pavo 画面内不生成钟表数字、表格或可读文件。

## 对白与声音规则

- 对白只承担必须被玩家听见、但无法仅靠画面准确建立的事实。
- 环境声必须与地点一致：雪山风声、河水、索桥金属声、帐篷布、无线电、车辆或登记地室内底噪。
- 每段最多两句短对白；说话人、情绪、动作落点明确。
- Pavo 原片不烧字幕、不自动转写；最终字幕根据验收后的音轨另行校时。
- 不用旁白替代关键行动，不用对白宣告画面中尚未发生的结果。

## Pavo 正式提示词规则

每份 `03_Pavo正式提示词.md` 必须逐段包含：

- 画幅：16:9，写实电影感，寒地勘探短剧，物理动作可信。
- 镜头：第一人称或明确的客观补充镜头；写清景别、运镜、焦点和结束构图。
- 人物连续：沈岚、老周、阿杰的年龄感、脸型、发型、寒地服装、背包与职责不漂移；阿杰保留耳机和医疗包。
- 玩家连续：不出现玩家正脸；队长左手白色绷带、握力不足和后续伤势必须匹配该分支。
- 道具连续：防水文件袋、地图、照片、坐标记录、样本箱、绳索、重装、补给只按状态卡出现。
- 硬性负向：无字幕、无可读文字、无UI、无水印、无品牌标识、无多余人物、无肢体畸变、无服装跳变、无伤手左右颠倒。

## 关键帧 K01/K02/K03

- K01：本段输入首帧。只能来自上一段经核对的实际成片尾帧；尚无成片时写明“待首帧验收”，不得写成已通过。
- K02：动作与构图参考。允许用于说明站位、视线、道具和动作方向，不代表节点完成状态。
- K03：本段目标尾帧。必须准确包含状态卡的离开状态，并为下一段留下稳定构图。
- 旧图片必须先通过八项事实、水印和人物连续性核对。Pavo 水印或水印未知图片只能留在 Web 审查区，不得进入本目录 `关键帧/`。
- 关键帧初始状态统一为“未验收”；人工确认后记录文件名、版本、审核人、日期和证据。

## 首尾帧承接契约

每份契约必须写清：

1. 输入来源：父节点哪一段实际尾帧；没有实际尾帧时写候选来源和“待替换”。
2. 输入必须继承：地点、时间段、人物站位、服装、伤手、文件/样本/设备/补给状态。
3. 本段允许变化：只列本段动作直接造成的变化。
4. 目标尾帧：K03 的稳定画面和必须可见事实。
5. 下一段去向：列出具体子节点；不同分支不得共用已经发生冲突事实的尾帧。
6. 验收记录：初始为“契约已写，实际首尾帧未验收”。

## 全局人物与道具连续性

- 玩家/队长：第一人称，不出现正脸；左手受伤并缠白色绷带。A1、D3-3 等分支加重后不得恢复。
- 沈岚：负责高品位样本、防水文件袋、地图、照片、坐标与勘探记录；原始资料由她保管时必须始终贴身。
- 老周：负责路线、天气与耗时判断；不替玩家作最终决定。
- 阿杰：保留耳机、医疗包和现场照护职责；不凭空承担路线或法律解释。
- 外部运输队只进入 C0/C3 及其终局；竞争者收购方只进入 D0/D2/D2-1。
- D2 交易对象仅含地图、照片、坐标和勘探记录，不含实体样本。

## 制作放行状态

```text
剧情逻辑锁定
→ 制作脚本锁定
→ K01/K02/K03 逐节点验收
→ Pavo 源片生成
→ 人物/动作/声音/字幕/水印验收
→ Web 独立终局视频绑定
```

任何阶段都不得用“文件已创建”替代内容验收，也不得把候选、参考或带水印素材标成正式通过。
