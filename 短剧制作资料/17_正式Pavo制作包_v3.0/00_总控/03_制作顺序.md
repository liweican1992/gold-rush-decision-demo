# 《最后十四天》v3.0 制作顺序

## 总原则

制作顺序以“先建立父节点事实，再制作子节点结果”为硬闸门。任何子节点不得先用想象首帧生成，再倒逼父节点修改尾帧。每个节点依次完成：文字脚本复核 → 旧素材八项核对 → K01/K02/K03 审核 → Pavo 源片 → 声画与字幕验收。

## 批次

1. 公共开场：INTRO → PRIMARY。先锁定队长第一人称、左手伤势、三名队友、地图、样本和土地购买期权。
2. 一级路线局面：A0、B0、C0、D0。每个节点必须让玩家在选择前获得三个行动所需的事实。
3. 二级行动节点：A1—D3。优先补 A3、B1、B3、C3、D1、D2 的不可逆事实。
4. 独立终局：按父节点成组制作；不得跨父节点共用已经发生的结果镜头。
5. 最终绑定：34 条结果视频逐条验收后绑定 Web，F1—F6 只在报告层聚合。

## 路线内顺序

- A：A0 → A1/A2/A3 → A1-1—A3-3。
- B：B0 → B1/B2/B3 → B1-1—B3-3。
- C：C0 → C1/C2/C3 → C1-1—C3-3。
- D：D0 → D1/D2/D3 → D1-1—D3-3；D2 只制作 D2-1 自动结果。
