# PRIMARY｜第一次战略选择｜节点状态卡

## 节点身份

- 类型：一级路线选择。
- 正式时间：发现黄金当天，登记窗口剩余14天。
- 地点：与 INTRO 连续的主帐篷木桌旁。
- 制作状态：制作脚本已写；K01 继承候选与 K03 候选 v1 已生成并完成事实/连续性预检，待人工验收；K02 未验收，视频未生成。

## 进入状态

- INTRO 已确认高品位样本、土地购买期权与14天登记窗口。
- 第一人称队长左手受伤；沈岚保管资料与样本，老周掌握路线，阿杰负责医疗。
- 三名队友保持 INTRO 尾帧的服装、站位和桌面道具关系。

## 离开状态

- 玩家清楚看见或听见四种一级策略：A立即翻山、B改走山谷、C等待48小时预报、D等待3—4周后安全撤离。
- 沈岚、老周、阿杰只提供事实和意见；最终选择由单个玩家作出。
- 尾帧停在三人等待决定的中景，不提前确定 A/B/C/D 任一路线。

## 玩家已知事实

- A 用速度换时间，但受天气和伤手影响。
- B 避开山脊，但路线更长。
- C 先获取更可靠预报，但消耗48小时。
- D 主动等待安全窗口，可能放弃当前14天登记机会。

## 不可逆事实

- 一旦进入 A/B/C/D，后续时间、位置与损失按所选路线独立累积。
- 路线选择不通过投票、随机或多数决定产生。

## 禁止误写

- 不得在 PRIMARY 画面提前出现暴风山口、断桥、运输队或竞争者。
- 不得用共享 X1/X2/X3 或 F1—F6 视频承接四条路线。
- 不得让任何队友替玩家宣布最终选择。
