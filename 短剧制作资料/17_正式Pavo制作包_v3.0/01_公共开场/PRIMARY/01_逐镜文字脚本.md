# PRIMARY｜逐镜文字脚本

## S01｜四种策略摆到桌面｜10 秒

| 时间 | 画面与动作 | 必须建立的事实 |
| --- | --- | --- |
| 0—2秒 | 从 INTRO 实际尾帧开始。镜头仍为第一人称围桌中景，沈岚把防水文件袋留在样本旁，三人视线转向队长。 | 与 INTRO 连续；证据仍由队伍控制。 |
| 2—5秒 | 老周用手指沿地图先划过陡峭山脊，再划向较长山谷路线；动作清楚但地图文字不可读。 | A翻山与B山谷是不同的时间/风险组合。 |
| 5—8秒 | 沈岚轻点无线电和天气图示意可等待48小时获取预报；阿杰看向受伤左手，再指向营地与安全撤离装备。 | C获取信息；D等待安全撤离；左手风险持续。 |
| 8—10秒 | 三人停止动作并看向镜头，队长受伤左手停在四个无文字方向标记之间；镜头稳定，不替玩家落选项。 | 单个玩家即将作出 A/B/C/D 选择。 |

## 剪辑边界

- 本段只建立四条策略，不表现任一路线已经执行。
- A/B/C/D 标签由 Web 或最终字幕层提供，Pavo 原片内不得生成字母 UI。
- K03 分别作为 A0、B0、C0、D0 的共同人物参考；各路线真正 K01 必须通过转场建立新地点。
