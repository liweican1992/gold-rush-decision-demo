# C3-3｜逐镜文字脚本

## S01｜执行选择｜10 秒

- 0—3秒：从C3稳定尾帧开始，队员确认本分支分工。
- 3—7秒：运输伙伴只装载人员设备，沈岚始终贴身保管原始资料箱，双方按边界协同行进。
- 7—10秒：动作完成，人员、资料、车辆或物资关系清楚。

- 结束要求：尾帧稳定至少1秒，必须与 C3-3 本段动作和状态卡一致。

## S02｜确定结果｜10 秒

- 0—4秒：以方向一致的连续动作或匹配剪辑推进，不跨入其他分支。
- 4—8秒：按时提交；运输能力补足，原始资料由队内控制，权益让渡和协调负担持续。
- 8—10秒：尾帧稳定展示确定结果和不可逆代价。

- 结束要求：尾帧稳定至少1秒，必须与 C3-3 本段动作和状态卡一致。

## 剪辑边界

- 每段只承担一个连续空间内的主要动作；跨地点或跨日只用明确分段与匹配剪辑。
- 不用字幕、UI、可读文件或旁白替代天气、样本、合作边界或确定结果。
