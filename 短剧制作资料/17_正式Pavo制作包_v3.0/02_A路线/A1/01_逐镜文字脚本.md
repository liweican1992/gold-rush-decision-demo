# A1｜逐镜文字脚本

## S01｜冲过山口并付出代价｜10 秒

- 0—3秒：从A0固定绳决策点开始，全队压低身体沿绳向上。
- 3—7秒：横风中一个非关键设备包脱落滑远；阿杰扶稳第一人称伤手。
- 7—10秒：镜头越过脊线进入背风坡，回看山脊已在身后。

- 结束要求：尾帧稳定至少1秒，必须与 A1 状态卡的离开状态一致。

## S02｜越岭后的第三次选择依据｜10 秒

- 0—3秒：风声减弱，镜头扫过背包上的空设备绑带和加重的左手绷带。
- 3—7秒：沈岚举起防水文件袋与核心样本，阿杰检查伤手。
- 7—10秒：老周指出前路并给出轻装四天、全队五天的差异，众人等待决定。

- 结束要求：尾帧稳定至少1秒，必须与 A1 状态卡的离开状态一致。

## 剪辑边界

- 每段只承担一个连续空间内的主要动作；跨地点和跨日只通过上述明确分段或匹配剪辑完成。
- 不使用字幕、UI、可读文件或旁白替代可见动作；确定结果不得写成可能发生。
