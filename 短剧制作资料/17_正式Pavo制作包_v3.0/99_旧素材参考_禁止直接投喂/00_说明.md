# 99｜旧素材参考｜禁止直接投喂

本目录只用于放置经过登记、但尚未获得正式制作资格的历史参考。当前 69 份历史图片已经复制到 Web 隔离审查目录，仍全部未验收；本目录不重复复制这些图片。

## 允许进入的内容

- 已记录原路径和 SHA-256 的人物、服装、构图或动作参考。
- 标明具体可用时间段、但仍需处理声音、字幕、水印或尾帧的旧视频片段说明。
- 对 A2、D1、D2 等冲突素材的禁用原因和可拆解参考元素。

## 禁止进入正式生产的条件

- Pavo 水印或水印状态未知。
- 八项事实任一项为 pending/conflict。
- 人物脸型、服装、队长左手、空间方向或昼夜连续性未关闭。
- 画面阶段与节点不符，例如用行动过程冒充节点完成状态。
- 旧 X1/X2/X3、共享 F1—F6 剧情、错误口播或烧录字幕。

## 升级流程

参考素材若要进入某个节点，必须在 `00_总控/04_素材复用与来源清单.md` 登记具体用途，完成八项事实与连续性核对，生成无水印的新版本，并由人工记录审核人、日期和证据。升级后复制到对应制作单元，不移动或覆盖原文件。
