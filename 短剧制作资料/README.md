# 《最后十四天》短剧制作资料

本目录保留 AI 短剧生产所需的正式资料、参考素材与过程文件。当前唯一正式入口是 `17_正式Pavo制作包_v3.0/`；其他目录在完成复用审查前都只作历史参考。

> 2026-09-08：v3.0 已完成 34 条路径的剧情逻辑修复。当前只放行文字基线，关键帧和成片尚未整体放行。

## 目录

- `01_剧情脚本/`：Pavo 2 集精简版和 5 集完整版，均含 DOCX 与 Markdown。
- `02_主线分镜/`：完整主线、互动点和镜头顺序。当前执行稿为 `最后十四天_逐镜生成版_大纲与分集分镜.docx`。
- `03_角色设定/`：角色圣经与写实/半写实角色参考图。
- `04_生成提示词/`：角色定妆、风格版本、生成流程与逐镜视频提示词。
- `05_样片与参考/`：已经生成且效果可接受的第一分镜视频及抽帧。
- `06_课程背景/`：战略管理案例的 PPT 关键页。
- `17_正式Pavo制作包_v3.0/`：当前正式剧情、时间线、34 条路径与后续 Pavo 生产资料的唯一入口。
- `99_过程文件/`：设计记录、文档生成脚本、渲染检查图和重复素材，不用于直接投喂视频平台。

## 当前制作基准

1. 剧情事实以 `17_正式Pavo制作包_v3.0/00_总控/` 为准。
2. 旧样片只能作为人物、场景或光线候选；声画与 v3.0 前后状态完全匹配后才能复制复用。
3. 后续每个节点优先使用上一段正式成片尾帧作为下一段首帧。
4. 每段只推进一个剧情信息，控制在 8–12 秒，并尽量只让一名角色说话。
5. 角色外貌必须遵守 `03_角色设定/角色圣经.md`，但与 v3.0 冲突的旧剧情说明无效。
6. 合同日期、地图文字和倒计时由 Web 后期叠加，不让 AI 视频生成；本项目不再使用队内投票结构。
