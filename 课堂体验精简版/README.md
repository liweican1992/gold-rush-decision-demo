# 课堂体验精简版 · 独立试案 v0.1

2026-09-10。旧R3.1剧本、Web和素材保持原样；本目录不替代旧版，不代表蔡老师已经认可改编。

唯一提供的教学原始材料是蔡临宁《战略管理-1.pdf》。没有老师口述录音或本次项目需求逐字稿，不能声称已还原未提供的口述内容。

## 这一版做什么

围绕淘金返程完成一次课堂导入。四个起始选择，每局1—2次关键决策；7条可达路径、3类结果状态。没有BU、基地经营、交易队或自动能力评分。竞争和合作留作后续讨论，不强行插入人物事件。文字试案使用既有改编中的部分时点，不沿用84条组合。

先读 `01_课件依据与教学对照.md`，再试玩 `试玩/index.html`。`试玩/story.mjs`为本版学生场景文字与决策的唯一数据源。概念解释在结局后展开，不显示在选择按钮旁。

## 本地运行

在本目录运行：

```sh
python3 -m http.server 5174 --bind 127.0.0.1 --directory 试玩
```

打开 http://127.0.0.1:5174/ 。旧版仍在5173，两者不共用存档。本版进度只在当前页面内，刷新会重置；暂不做账号、后台、统计或视频。

测试：`node --test 试玩/story.test.mjs`。

## 验收目标（待实际试读）

- 学生能说清为何返城、期限失去的是什么，不需要导演旁白救场。
- 学生能说出一个外部条件、一个自身约束、一个主动接受的代价。
- 学生能根据自己当时的信息解释选择，而非只根据结局猜最优按钮。
- 老师能将体验对应到PPT第11、13页；后续课程只作引出，不宣称一次游戏已教完战略管理。
