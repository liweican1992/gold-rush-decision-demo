# 精简结构与视频边界

## 本版结构

开场分两小段：发现与购买机会、为何本人返回。随后给四种策略：立即翻山、立即山谷、等2—3天信息、等3—4周稳定。前3种最多再作一次选择，最后一种直接看到返程和复盘。

| 路径 | 本次示例的实际后果 | 结果类别 |
| --- | --- | --- |
| 山路继续 | 第5天越岭，第9天到镇并完成手续；伤手加重 | 按期、照护代价较高 |
| 山路避险两天 | 第5天风势下降再走，第7天越岭，第11天完成手续 | 按期、消耗时间缓冲 |
| 山谷延长行进 | 第14天06:00到镇，08:30完成，距截止半小时；明显疲劳 | 按期、休息代价较高 |
| 山谷保持节奏 | 第16天到镇，接受超期 | 原购买窗口失去 |
| 等消息后翻山 | 第3天出发，风暴高峰仍在低处，第8天越岭，第12天完成手续 | 按期、消耗时间缓冲 |
| 等消息后走谷地 | 第3天出发，16天返程，第19天到镇 | 原购买窗口失去 |
| 长期等待 | 第24天出发，16天返程，第40天到镇 | 原购买窗口失去 |

按期结果合并为两个状态：较高身体代价、消耗时间缓冲；第三类为超期。每条尾声仍显示实际历程，不能把7条抹成完全相同的一句话。全路径所有人返回；这是本轮课堂试案的固定示例结果，不能推导真实行动没有生命风险。

精简掉的并非“错误内容”：旧版折返、C中途转谷地、同行合作和基地经营仍保留在旧目录与旧Web。本版不依赖它们运行。不是一个取代所有旧稿的最终定稿。

## 信息纪律

- 初选只显示常见行程范围、天气待确认、受伤和期限；不提前给确定归期。
- 选择等消息后，先交代第2天确认暴风，再交代第3天通道未封断。这两段是已选择等待策略的执行，不额外加按钮凑决策。
- 固定事件用于对比选择，不按按钮临时制造奖励/惩罚。复盘强调本次实现的结果不证明事前决策必然正确。
- 默认没有自动画像，只回顾行为和学生自述。没有自述就显示未填写。

## 视频承担什么

AI视频用来呈现原先需要口述想象的事情：营地发现、手部短暂失力、山路与谷地差异、风势变化、团队疲惫、等待中流逝的日子和回城。精确期限和规则由可回看的文字承担，不让一个视频塞进所有说明。

先按场景模块整理：营地发现/约定、路线介绍、山路现场、河谷盘点、天气公告与等待、到镇手续/照护、超期返城。这里只是内容分组，不是批准7条视频任务，也未统计所有差异片段。二级选择后的不同动作需单独说明，不能一段成功镜头覆盖所有后果。

旧素材只列为待复核候选：山景、谷地、营地、风雪、休整。优先保留环境素材；带样本交付、交易、开采或不符前情伤势的画面不能直接绑定。当前未逐一视觉验收，未复制、删除、生成或宣布任何资产生产放行。

## 下一次试读

先让用户完整走一局，再换一条路线对照。教师核对第11、13页是否被体现；学生回答一项外部条件、一项自身约束、一项代价。若仍需要口头补规则，改对应场景，不增加机制。试玩时长尚未实测，不承诺“几分钟学会战略管理”。
