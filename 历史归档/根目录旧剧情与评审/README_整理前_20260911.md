# 淘金决策局 · 战略管理互动 Demo

桌面端互动电影 Demo。当前正式剧情为 v3.0，玩家从公共开场进入三层因果决策：

- 一级选择：立即翻山、改走山谷、等待 48 小时预报、等待 3–4 周安全撤离。
- 二级行动：每条路线进入一个局面，再选择 3 个行动方案，共 12 个二级节点。
- 第三次选择与结果：除 D2 自动交易结果外，每个二级节点有 3 个路线专属选择，共 34 条独立因果终局。
- 结果复盘：F1—F6 只作战略画像分类，不再播放共享剧情。

当前 34 条剧情逻辑和制作级文字包已建立；关键帧与最终视频仍需逐条验收。尚未生成的分支视频会显示剧情占位页，历史图片只在隔离审查区展示，不代表正式通过。

## 启动

```bash
npm install
npm run dev -- --host 127.0.0.1
```

浏览器打开 `http://127.0.0.1:5173/`；导演分支图位于 `http://127.0.0.1:5173/docs/story-map/`。

## 验证

```bash
npm test -- --run
npm run typecheck
npm run build
```

## 视频接入规则

旧 Demo 视频仍保留在 `public/videos/demo/`。v3.0 的 34 条独立终局视频使用 `public/videos/web/finales/<path-id>.mp4`，正式制作依据见：

- `短剧制作资料/17_正式Pavo制作包_v3.0/00_总控/00_唯一入口.md`
- `短剧制作资料/17_正式Pavo制作包_v3.0/00_总控/01_正式时间线与状态总表.md`
- `短剧制作资料/17_正式Pavo制作包_v3.0/00_总控/02_34条路径总表.md`
- `短剧制作资料/17_正式Pavo制作包_v3.0/00_总控/07_制作文件规范.md`

制作顺序为公共开场 → A0/B0/C0/D0 → A1—D3 → 34 条独立终局。每个新视频必须使用上一段真实成片尾帧作为 K01；K03 只定义目标尾帧，生成完成后必须用新的实际尾帧替换下一段输入。
