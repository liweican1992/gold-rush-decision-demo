# 淘金决策局 · 战略管理互动 Demo

桌面端互动电影 Demo。玩家先观看真实视频公共开场，再进行两层固定决策：

- 一级选择：立即翻山、改走山谷、等待 48 小时预报、等待 3–4 周安全撤离。
- 二级选择：每条路线进入一个新局面，再从 3 个行动方案中选择。
- 结果复盘：共 12 个可比较结局，展示期限、人员、团队能力、矿权状态与战略启示。

当前公共开场已接入真实视频。尚未生成的分支视频会显示剧情局面占位页，仍可完整演示全部选择路径；补齐视频后无需修改流程代码。

## 启动

```bash
npm install
npm run dev -- --host 127.0.0.1
```

浏览器打开 `http://127.0.0.1:5173/`。项目仅面向桌面 Web，建议使用 1440 × 900 或相近窗口。

## 验证

```bash
npm test -- --run
npm run typecheck
npm run build
```

## 视频接入规则

视频统一放在 `public/videos/demo/`。系统已经约定 17 个节点：1 个公共开场、4 个路线局面、12 个路线结果。稳定文件名见：

- `短剧制作资料/08_项目清单/故事节点图.json`
- `短剧制作资料/08_项目清单/OpenMontage场景计划.json`
- `短剧制作资料/08_项目清单/OpenMontage素材清单.json`

推荐先生成 `A0 → B0 → C0 → D0` 四个局面视频，再分别补齐各路线的三个结果视频。每个新视频必须使用上一段真实成片尾帧作为连续性输入；目标尾帧只用于约束，不直接作为下一镜首帧。

## 关键文件

- 剧情节点与所有文案：`src/demo/story.ts`
- 流程状态机：`src/demo/flow.ts`
- Web 主页面：`src/MainlineDemo.tsx`
- 选择与结果组件：`src/components/`
- 视觉样式：`src/styles.css`
- 公共开场视频：`public/videos/demo/intro.mp4`
- 导演分镜文档：`短剧制作资料/02_主线分镜/最后十四天_逐镜生成版_大纲与分集分镜.docx`

当前版本不包含随机事件、伪造投票、多人联网、登录、数据库、移动端适配和后台报表。
