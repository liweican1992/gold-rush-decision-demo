# 淘金决策局：三层固定决策树设计

日期：2026-09-01

## 1. 设计目标

把当前“播放公共开场 → 四选一 → 直接显示结果”的单轮 Demo，扩展为可继续分叉的战略管理教学游戏：

1. 公共开场结束后，学生在四种初始战略之间选择。
2. 每条战略播放独立剧情，呈现该选择自然造成的新局面。
3. 每条战略都提供三个与该局面对应的二次选择。
4. 二次选择播放独立结果视频，再进入战略复盘。

本版不使用随机事件。相同选择必定进入相同剧情，保证课堂演示稳定，也让学生能够比较不同班级、不同小组的决策逻辑。

## 2. 与蔡老师战略管理课的对应关系

PPT 的案例核心不是寻找唯一正确答案，而是在明确目标后，评估外部环境与自身资源能力之间的匹配关系。决策树必须持续呈现以下变量：

- 外部环境：天气、地形、竞争者、登记期限；
- 资源与能力：受伤左手、队员状态、设备、补给、资金、信息；
- 战略目标：取得矿权、保护生命、保存团队与资本；
- 战略特征：权衡取舍、不确定性、时间压力、竞争和不可逆性；
- 动态调整：前一个选择改变后续可用选项，而不是一次选择决定一切。

四条一级路线分别突出四种战略逻辑：

| 路线 | 核心逻辑 | 课程讨论点 |
|---|---|---|
| A 立即翻山 | 用高承诺换取速度 | 风险承受、不可逆损失、承诺升级 |
| B 改走山谷 | 保护能力但牺牲速度 | 战略目标与执行路径是否匹配 |
| C 等待 48 小时 | 用时间购买信息与选择权 | 信息价值、延迟承诺、机会成本 |
| D 等待安全撤离 | 改变目标并保存资源 | 退出战略、目标排序、沉没成本 |

## 3. 总体结构

```text
公共开场
  → 一级选择 A / B / C / D
  → 路线专属局面视频
  → 路线专属二次选择 1 / 2 / 3
  → 二次选择结果视频
  → 结果指标 + 路径回放 + 战略复盘问题
```

本次完整竖切包含：1 段公共开场、4 段路线局面视频、12 段结果视频，共 17 段。以后可以把任意结果节点替换成新的选择节点，继续增加层级。

## 4. 一级选择顺序

保持课堂认知顺序“继续争取机会 → 降低风险 → 购买信息 → 主动退出”：

| 编号 | 选项 | 初始取舍 |
|---|---|---|
| A | 立即翻山 | 7–10 天；速度最快，伤势与暴风风险最高 |
| B | 改走山谷 | 2–3 周；人员风险较低，可能错过登记期限 |
| C | 等待 48 小时预报 | 先消耗两天，换取天气信息后再行动 |
| D | 等待 3–4 周安全撤离 | 人员安全优先，主动放弃登记时间窗口 |

界面不显示“激进型、保守型、正确、错误”等先验标签，只显示事实、时间和核心风险，避免诱导学生。

## 5. A 路线：立即翻山

### A0 · 路线局面视频

队伍进入山脊第三天，横向暴雪提前抵达，固定绳被风拉紧。队长左手开始失力，前方山口仍隐约可见。老周喊：“山口就在前面！可这阵风，比预报早了一天。”

状态：剩余 11 天；天气恶化；左手失力；矿权仍有机会。

### A 路线二次选择

| 节点 | 选择 | 结果视频 | 战略概念 |
|---|---|---|---|
| A1 | 继续冲过山口 | 队伍及时越过山脊并保住登记窗口，但队长左手伤势严重、部分设备遗失 | 高承诺、高收益与不可逆代价 |
| A2 | 原地扎营等待一天 | 队伍保住人员和设备，风势减弱后通过；时间优势缩小，但仍有狭窄登记窗口 | 韧性、缓冲与时间成本 |
| A3 | 撤回并转走山谷 | 返回过程安全，但路线切换消耗已投入的三天，最终错过期限 | 转换成本、沉没成本与及时止损 |

复盘问题：在什么条件下，坚持不再是勇敢，而是承诺升级？

## 6. B 路线：改走山谷

### B0 · 路线局面视频

进入山谷第六天，融雪让河道突然上涨，原有木桥被冲断。队伍安全，但携带的勘探设备拖慢速度。沈岚说：“绕过去至少再多四天。照这个速度，十四天不够。”

状态：剩余 8 天；人员稳定；道路中断；矿权时间临界。

### B 路线二次选择

| 节点 | 选择 | 结果视频 | 战略概念 |
|---|---|---|---|
| B1 | 立即涉水强渡 | 队伍按时抵达，但部分样本和补给进水，登记证据不完整 | 局部冒险与系统性后果 |
| B2 | 绕行四天 | 全员和设备安全抵达，但矿权已经进入公开程序 | 安全优化与战略目标失配 |
| B3 | 丢弃重型设备轻装前进 | 队伍在截止前抵达并完成登记，但失去关键设备和后续开采能力 | 资源取舍、短期目标与长期能力 |

复盘问题：一条更安全的路径，如果不能实现目标，是否仍然是好战略？

## 7. C 路线：等待 48 小时预报

### C0 · 路线局面视频

两天后，无线电预报确认山脊将在三十六小时后封闭，队长左手略有恢复，但只剩十二天。老周收起天气图：“答案有了。可窗口也只剩一天半。”

状态：剩余 12 天；信息增加；短暂山口窗口；左手略有恢复。

### C 路线二次选择

| 节点 | 选择 | 结果视频 | 战略概念 |
|---|---|---|---|
| C1 | 抢在封山前轻装翻山 | 队伍赶上窗口并及时登记，但只能携带少量样本，后续价值评估受限 | 信息驱动行动与剩余风险 |
| C2 | 根据预报改走山谷 | 避开暴风并保存团队，但两天等待叠加长路线，最终错过期限 | 正确信息不等于可行战略 |
| C3 | 引入当地运输伙伴 | 让渡部分权益换取雪地运输能力，队伍按时抵达并保住部分矿权 | 能力获取、合作与控制权稀释 |

复盘问题：信息的价值，应当用准确度衡量，还是用它能否改变行动衡量？

## 8. D 路线：等待安全撤离

### D0 · 路线局面视频

队伍开始打包撤离。第二天风雪短暂减弱，无线电同时收到竞争者提出的矿区信息收购报价。沈岚看向桌上的矿石：“我们已经决定保人，但还没决定怎样退出。”

状态：剩余 12 天；人员安全；机会尚未完全关闭；竞争者出现。

### D 路线二次选择

| 节点 | 选择 | 结果视频 | 战略概念 |
|---|---|---|---|
| D1 | 坚持等待并安全撤离 | 三周后全员安全离开，矿权被他人取得 | 目标排序与一致性执行 |
| D2 | 出售勘探信息与优先权 | 队伍安全撤离并收回大部分投入，但失去控制权和未来上涨收益 | 退出变现、风险转移与机会成本 |
| D3 | 利用天气窗口重返矿区 | 队伍重新追赶，但反复转换消耗时间和补给，最终只保住部分权益 | 战略反转、转换成本与执行一致性 |

复盘问题：主动退出是失败，还是另一种资源配置决策？

## 9. 视频与关键帧连续性

- 四段路线局面视频都从公共开场“三名队友等待决定”的同一尾帧开始。
- 每段局面视频的尾帧必须清楚保留人物站位、关键道具和下一次选择所需的环境信息。
- 每条路线下的三个结果视频，共用该路线局面视频的同一尾帧作为首帧。
- 视频只负责人物、动作、环境和对白；字幕、按钮、天数和指标全部由 Web 渲染。
- Pavo 提示词统一要求：16:9、第一人称、写实电影实拍质感、低锐化、自然肤质、连续镜头、不要字幕和可读文字。

## 10. Web 数据与状态结构

剧情不再用扁平 `RouteOption[]` 表示，而改成可扩展节点图：

```ts
type StoryNode = VideoNode | ChoiceNode | EndingNode

type VideoNode = {
  kind: 'video'
  id: string
  video: string
  subtitles: SubtitleCue[]
  next: string
}

type ChoiceNode = {
  kind: 'choice'
  id: string
  prompt: string
  options: Array<{
    id: string
    label: string
    factHint: string
    target: string
  }>
}

type EndingNode = {
  kind: 'ending'
  id: string
  metrics: {
    days: string
    people: string
    capability: string
    claim: string
  }
  lesson: string
  reflectionQuestion: string
}
```

运行状态保存当前节点、决策路径和当前指标。所有节点跳转均由配置决定，不把分支判断散落在 React 组件中。

## 11. 页面流程与课堂证据

结果页显示：

- 决策路径，例如 `A 立即翻山 → A2 原地扎营`；
- 剩余时间、人员安全、团队能力、矿权状态；
- 本次选择获得了什么、牺牲了什么；
- 一道与该路径对应的战略复盘问题；
- “回到本路线二次选择”“回到一级选择”“重新播放开场”三个操作。

课堂演示不使用伪造投票数，也不宣告标准答案。未来接入多人投票时，应记录初始选择、二次选择、状态变化和学生解释，供教师比较不同小组的战略逻辑。

## 12. 异常与降级

- 视频缺失：显示该节点的剧情概要卡，仍允许继续做下一次选择。
- 视频加载失败：保留当前路径和指标，不重置游戏。
- 快速连续点击：第一次选择后立即锁定，避免触发多个节点。
- 返回上一级：恢复进入该节点前的指标快照，而不是沿用后续结果。
- 浏览器刷新：演示版回到启动页；后续可增加本地进度恢复。

## 13. 验收标准

1. 公共开场结束后显示 A/B/C/D 四个一级选项，顺序固定。
2. 四个一级选项分别进入不同的局面视频和不同的二次选择。
3. 每条路线有三个二次选择，共十二条可独立体验的结果路径。
4. 每个结果页显示准确路径、四项状态和对应复盘问题。
5. 任意视频缺失时仍能完整走通选择与结果流程。
6. 返回一级或二级选择时不需要重播此前视频。
7. 无随机事件；相同路径在每次演示中产生相同结果。
8. 桌面端 1440×900 下无横向滚动、按钮遮挡或字幕溢出。
9. 自动测试覆盖节点存在性、目标可达性、无死链、返回快照和全部十二条终点。
10. TypeScript 检查、测试、生产构建和浏览器全路径抽查通过。

## 14. 本轮实施顺序

1. 先把 Web 数据结构升级为节点图，并用剧情概要卡打通全部十二条路径。
2. 恢复四个一级选项，接入四组二次选择和结果页路径回放。
3. 按 A0、B0、C0、D0 顺序生成四段局面视频与关键帧。
4. 每完成一个局面尾帧，再生成该路线 A1–A3、B1–B3、C1–C3、D1–D3 三段结果视频。
5. 逐段替换占位素材、识别真实音轨生成字幕，并进行首尾帧连续性检查。

## 15. 2026-09-02 全分叉审查修订

### 15.1 统一结果视频结构

除已经完成闭环的 A1 外，二级结果视频不再只展示“开始执行选择”。每个结果统一采用两段式：

1. 第一段约 10 秒：执行选择，明确人物动作、资源取舍和即时风险；
2. 第二段约 10 秒：推进时间并兑现结果，画面或对白必须直接支持 Web 结果页的时间、人员、能力和矿权状态。

允许用自然环境变化、装备状态变化和抵达新地点表达时间推进；不使用片中文字或生成字幕。字幕仍由 Web 根据成片音轨单独配置。

### 15.2 统一时间账

| 节点 | 决策发生时点 | 后续耗时 | 结果时点 |
|---|---:|---:|---:|
| A0 | 第 3 天，剩余 11 天 | — | 山脊风暴提前 |
| A1 | 第 3 天 | 约 6 天 | 剩余 5 天，保留登记机会 |
| A2 | 第 3 天 | 等待 1 天，再行进约 6 天 | 剩余 4 天，窗口狭窄 |
| A3 | 第 3 天 | 下撤并转山谷，累计超过 14 天 | 超期，矿权失去 |
| B0 | 第 6 天，剩余 8 天 | — | 断桥阻路 |
| B1 | 第 6 天 | 强渡并继续行进约 7 天 | 剩余 1 天，材料受损、审核不确定 |
| B2 | 第 6 天 | 基础路程约 5 天，加绕行 4 天 | 超期至少 1 天 |

### 15.3 路线逻辑修订

- A3 对白统一为“前三天白走了，再走山谷，赶不上登记了”，避免把已投入三天误读为下撤另需三天。
- B3 的断桥旁存在一座只能承载人员和轻装的检修索桥，重型设备无法通过。丢弃设备因此同时解决通行和速度问题。
- C0 必须明确说出“山口三十六小时后封闭”，不能只说“答案有了”。
- C3 在 C0 无线电信息中预告附近有当地雪地运输队，避免伙伴凭空出现。
- D0 从撤离第二天调整为撤离第六天，并由沈岚明确说出竞争者正在收购勘探资料。
- D2 交易对象是勘探数据、样本和合同允许转让的购买优先权，不描述为出售已经拥有的矿区。
- D2 的竞争者代表不在偏远营地瞬间出现；第一段通过无线电达成原则交易，第二段在安全基地完成资料交付。
- D3 更名为“取消撤离，轻装抢登记”。队伍仍在撤离途中，不使用“重返矿区”；结果改为最后时限完成登记，同时付出补给耗尽、设备留守和团队疲劳的转换成本。

### 15.4 结果一致性验收

每条结果线在交付 Pavo 前必须同时满足：

1. 阻碍与行动之间存在直接因果关系；
2. 第二段画面或对白支持结果页四项指标；
3. 天数能从统一时间账推导，不使用无依据的“及时”“最后”或“部分权益”；
4. 首帧承接路线局面真实尾帧，中间帧同时作为第二段首帧；
5. 角色、服装、道具、地形方向和第一人称伤手连续；
6. Pavo 成片完成后再依据真实音轨生成 Web 字幕。
