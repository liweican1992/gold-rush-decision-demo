# 《最后十四天》历史关键帧复用与 Web 展示设计

日期：2026-09-08  
状态：待用户书面确认后实施

## 目标

保留此前投入产生的有效关键帧，并让用户在本地剧情树 Web 中看到复用状态；同时不把旧剧情画面误标为 v3.0 已验收素材。

本轮只整理和展示既有关键帧，不生成新关键帧，不删除或覆盖历史文件。

## 状态模型

每张图片只属于以下一种状态：

1. **已绑定候选**：画面主体、场景和关键事实与 v3.0 节点一致，可显示在节点卡片上；仍需后续检查水印、人物连续性和首尾帧衔接。
2. **仅作参考**：人物、服装、光线或构图可复用，但时间、位置或事件状态不符合该节点；只进入历史素材审查区，不作为节点正式画面。
3. **冲突禁用**：画面会引入错误事实；保留源文件用于追溯，但禁止进入 Pavo 或节点卡片。

Web 不使用“已有关键帧”这种容易误解为已验收的单一标签。节点图片必须显示对应状态徽标。

## 文件与数据流

- 历史原件保留在 `短剧制作资料/09_路线制作包/`，不得移动、重命名或删除。
- Web 需要使用的图片复制到 `public/images/choice-frames/reuse-v3/`，名称使用节点 ID，不直接引用历史目录。
- 在 `短剧制作资料/17_正式Pavo制作包_v3.0/00_总控/` 增加复用清单，记录节点、状态、原路径、新路径、SHA-256 和判定理由。
- `redesignedStory.ts` 保存节点已绑定候选；独立的历史审查清单保存“仅作参考”和“冲突禁用”素材。

## Web 呈现

1. 节点卡片左上角增加图片状态徽标：`已绑定候选`、`仅作参考`、`待生成`。
2. A/B/C/D 路线筛选继续控制节点与复用审查内容。
3. 剧情验收总览下增加“历史关键帧复用审查”区域，展示首批素材缩略图、目标节点、状态和判定原因。
4. 冲突禁用素材只在审查区展示，不绑定节点；视觉上使用红色禁用标记。
5. 点击节点详情时同时显示制作状态和关键帧复用状态，避免把“脚本锁定”误读成“图片/视频已验收”。

## 验收标准

- Web 能看到首批15类历史素材的复用结论。
- B1、B3、C3、D1 的可用旧图出现在对应节点卡片。
- C0、C1、D0、D3 不冒充正式节点关键帧。
- D2 旧交付图和 X/F 共享图明确显示为冲突禁用。
- 所有复制图片都有来源路径和 SHA-256；历史原件保持不变。
- 34条路径、v3.0 时间与剧情自动校验继续通过。
