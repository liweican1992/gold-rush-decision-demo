## 四维状态与用途关系

状态记录的主体是“图片版本＋目标节点＋具体用途”，不是图片的全局结论。同一图片有多个用途时，建立多条用途记录，资产文件只登记一次。

| 维度 | 允许值 |
| --- | --- |
| 复用判断 | 候选待审 / 仅作参考 / 禁止用于该节点 |
| 镜头阶段 | 公共入口 / 节点决策状态 / 行动开始 / 行动过程 / 直接后果 / 独立终局 |
| 修复方式 | 无需修复待验 / 可裁切待复核 / 可局部重绘待复核 / 需换帧 |
| 制作验收 | 未验收 / 关键帧已验收 / 视频待验收 / 视频已验收 |

镜头阶段只能填表中的单一值。扎营、握手、整装、检查、撤收准备等填写在独立的“动作说明”字段，不作为阶段枚举。每条用途记录另有用途 ID、镜头位置、拟定时间地点及证据，不把拟用途时间当成图片已证事实。

- 公共入口：INTRO、PRIMARY 所代表的公共开场或战略选择入口。
- 节点决策状态：玩家面临该节点后续选择时的规定状态；适用于 A0/B0/C0/D0，也可适用于等待完成后的 D1 撤收准备等。
- 行动开始：所指行动刚开始或准备起行，必须说明相对于哪个选择或镜头。
- 行动过程：所指行动仍在途中，不能代表稍后的抵达或超期状态。
- 直接后果：前置行动完成所产生的状态，不代表后续独立终局已经发生。
- 独立终局：具体路径的确定结果；不能用 F 类别替代路径 ID。

“禁止用于该节点”限制指定用途，不删除原图或否定其全部元素。禁用的用途记录与“人物/道具/构图参考”记录分开；后者没有主图资格。

“可修复”不等于“已修复”。制作验收必须指向资产版本、用途 ID、审核人、日期和证据；未有验收证据时只能是未验收。视频验收值只用于关联的具体视频版本，不得赋予静态图片或用于整节点自动升级。本批历史图片初始全部为未验收。

## 展示准入规则

### 八项核对

所有拟绑定主图都必须核对：时间、地点、人物、装备、伤势、样本/资料、天气、不可逆后果。每项记录以下结果之一：

- 画面已证实：描述可见证据。
- 画面未呈现但外部已建立：指明哪段正式对白、相邻镜头或 Web 文字建立该事实，记录路径/节点/镜头号和具体内容；不能只写“字幕补充”。
- 待证实：没有足够证据，不能当作通过。
- 冲突：列出画面与正式事实的具体矛盾。

不要求单帧呈现全部文字事实，但画面不得与正式事实冲突。Web 文字可建立时间等非可见事实，不能把已经越岭改称尚未越岭、把同岸改称对岸。计划中的补拍不是已存在证据。

### 三种展示位置

1. 审查区：允许展示所有已登记历史图片，保留原状与水印，显示冲突和未证实项。存在图文冲突、未解决的人物连续性问题、任一待证实项的文件，只进入审查区。
2. 过程素材区：仅展示无 Pavo 水印、对该过程用途八项核对无冲突/待证实、人物连续性已核对的开始/过程参考图。必须注明“历史过程参考·未验收，不代表本节点完成状态”。只进入审查区的文件在此最多提供文字审查入口，不重复展示图片。
3. 节点主图：必须有显式的节点＋用途绑定；镜头阶段须匹配该节点规定状态，八项全部为画面已证实或外部已建立，人物连续性无未解决问题，修复方式为无需修复待验，无 Pavo 水印，无其他未解决视觉缺陷。候选待审且完成这一初审门槛后，可以显示“候选已绑定·未验收”；这不等于人工关键帧或视频验收。

主图初审失败则不绑定，已有不合格绑定撤下，只在审查区保留。没有主图也可以完成本批展示，不设“每节点至少一张”的配额。未来经修复的版本必须重走同样门槛，不能沿用原图的通过状态。

**Pavo 水印图只能进入审查区，不得作为节点主图或过程区图片，也不得作为正式关键帧。** 不裁切或遮挡水印制造已处理假象。水印未知按未完成核对处理。无水印源图也必须独立初审，不能自动替换。
