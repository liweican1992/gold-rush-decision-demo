# 《最后十四天》历史关键帧复用与 Web 展示设计

日期：2026-09-08  
状态：已吸收独立审查意见，待用户确认后实施

## 目标

保留此前投入产生的有效关键帧，并让用户在本地剧情树 Web 中看到复用状态；同时不把旧剧情画面误标为 v3.0 已验收素材。

本轮只整理和展示既有关键帧，不生成新关键帧，不删除、覆盖、改名或移动历史文件。

## 判定模型

图片不能只用一个“可用/不可用”状态概括。复用清单必须同时记录四个独立维度：

| 维度 | 允许值 |
| --- | --- |
| 复用判断 | 候选待审 / 仅作参考 / 禁止用于该节点 |
| 镜头用途 | 行动开始 / 行动过程 / 直接后果 / 独立终局 |
| 修复方式 | 无需修复待验 / 可裁切待复核 / 可局部重绘待复核 / 需换帧 |
| 制作验收 | 未验收 / 关键帧已验收 / 视频待验收 / 视频已验收 |

“禁止用于该节点”只限制该文件与该节点用途的组合，不代表删除图片或否定其中所有人物、道具和构图价值。“可裁切/可重绘”也不自动提升为可用，修复后的文件必须重新验收。

Web 不使用“本节点已有关键帧”这种容易误解为已验收的统一标签。正式通过前一律使用非绿色的“候选已绑定·未验收”“过程素材·仅参考”“禁止用于该节点”等标签。

## 文件处理与清单

1. 在复制之前先建立逐文件清单，不使用“A2现有图”等模糊名称。
2. 每条记录包含：源路径、目标节点、镜头用途、四维状态、可见事实、未证实事实、冲突、修复方式与源文件 SHA-256。
3. 源文件不移动、不改名、不覆盖、不删除。审查副本与未来 Pavo 可用资产分开管理。
4. 完成逐文件初审、且可能承接节点的文件复制到 `public/images/choice-frames/legacy-candidates/`；复制后核对源与副本 SHA-256。
5. Web 需要展示的“仅作参考”和“禁止用于该节点”图片，使用独立的 `public/images/choice-frames/review-only/` 审查副本；该目录不得作为 Pavo 输入源或节点主图来源。
6. 旧提示词、旧字幕和旧对白不会因图片复制而自动继承。

## Web 展示

1. 在剧情验收总览下增加“历史关键帧复用审查”区，展示逐文件缩略图、目标节点、镜头用途、状态、来源、已证实/未证实事实和判定理由。
2. 节点主图默认只承载与该节点规定阶段匹配的画面；行动开始/过程帧放在详情的“过程素材”区。
3. 当前 A2、A3、C0、D0 主图撤下或降级到过程/参考区；不得用时间标签解释画面中已经发生的相反事件。
4. “待生成”改成“未绑定合格帧”，并显示是否“有旧素材待审”。
5. 图片无障碍说明改成“历史候选图，未验收”等准确文案。
6. “脚本逻辑0项错误”旁增加“该校验不覆盖图片事实和声画连续性”。
7. 带 Pavo 水印的图可进入审查区并保留水印，但不得作为正式关键帧；界面不得用遮挡水印制造已处理假象。

## 实施顺序

1. 生成逐文件清单与源文件哈希。
2. 撤下当前错位主图，完成 A2、A3、B1、B3、C3 的镜头用途重分类。
3. 核对队长袖口与左手、老周外观、阿杰医疗包、资料归属、河岸方向等连续性偏差。
4. 先上线 Web 审查区和状态隔离，再决定哪些文件复制为候选。
5. 正式视频生产前另过人工关键帧验收。

## 验收标准

- Web 按真实图片数展示逐文件清单，不用“15类”代替资产数量。
- A2 越岭图、A3过程图、B1河岸图、B3同岸图、C0/D0参考图不再占对应完成状态主图。
- B1登记站图和 A2清晨整装图完成八项检查：时间、地点、人物、装备、伤势、样本/资料、天气、不可逆后果。
- 所有复制候选的源/副本哈希一致；参考/禁用文件没有被误放入生产资产。
- 带水印历史图没有被标为正式关键帧。
- 任何节点都不会把“有候选图”显示成“关键帧已验收”。
- 34条终局数量、路径 ID、剧情校验与项目测试继续通过。

## 独立审查后的设计修正

- 撤销“每张图片只能属于一个状态”，改为图片—目标节点—镜头用途的多维关系。
- 撤销 A2 当前 Web 图、A3、B3 直接绑定完成状态的方案。
- 将 B1 河岸图和 C3 握手图限定为过程素材，结果位需另审。
- D2 保持原图禁用，但允许回收人物与握手构图，不扩大为整张图无价值。
- 将 B2、C2 与 B1 登记站素材补入回收清单。
