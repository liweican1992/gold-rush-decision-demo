# A1 穿越山口连续性修复设计

## 目标

把 A1“继续冲过山口”从一段 9–10 秒的假位移，改成三段可由 Pavo 分别生成、首尾帧连续的真实空间推进。观众必须先看到队伍登上山口鞍部，再看到跨过分水岭，最后到达另一侧背风坡，才允许对白说“山口过了”。

## 方案比较与选择

1. 单段长提示词：成本最低，但视频模型容易压缩空间，已经失败。
2. 三段连续镜头：每段只承担一个明确动作，用上一段尾帧作为下一段首帧。连续性和可控性最好，采用此方案。
3. 多机位蒙太奇：越岭感最强，但人物一致性和镜头衔接风险更高，不适合当前 Pavo 逐镜工作流。

## 三段结构

### A1-1 登上鞍部

从 A0 的真实尾帧继续。老周在前方拉绳，阿杰和沈岚依次顶风向上。镜头必须持续产生明显向前、向上的位移；尾帧位于狭窄鞍部最高点，画面同时露出身后的来路与前方另一侧下降坡，但此时不能说“山口过了”。

### A1-2 跨过分水岭

从鞍部最高点开始。三名队友翻过岩脊，身体由上攀姿态转为向下侧身行进；摄影机跟随越过脊线，原来位于前方的尖峰转到身后。一只设备箱固定带断裂，箱体滑落到来路一侧。尾帧必须清楚看到队伍已经处于山口另一侧，脊线在身后上方。

### A1-3 抵达背风坡

从另一侧下降坡开始。队伍继续下降一段可感知距离，风雪明显减弱，阿杰扶住沈岚，老周停下回望第一人称队长受伤的左手。只有此时阿杰才说：“山口过了。可设备丢了一箱，你的手也撑不住了。”

## 视觉连续性约束

- 第一人称队长始终穿锈红外套，左手缠米白绷带并握安全绳。
- 老周：深色外套、酒红针织帽、短灰黑胡须；阿杰：锈红外套、短黑发、无帽无胡须；沈岚：深蓝外套、黑发低束。
- 冷蓝阴天天光、真实电影摄影、自然皮肤和布料纹理；禁止油画感、插画感、脏污颗粒、过度锐化、文字、水印和新增人物。
- 三段地形必须不可逆地推进：山口前上坡 → 鞍部最高点 → 山口后下降坡。不能在同一块岩石附近原地踏步。

## 验收标准

- 任取每段首尾帧，人物相对山脊和远景位置有明显变化。
- A1-2 尾帧能凭画面判断队伍已跨越分水岭。
- “山口过了”只出现在 A1-3。
- 三段可分别失败重做，不影响另外两段。
